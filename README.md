# 76052 Road Gaps

Independent map of where roads in ZIP 76052 (Haslet and far north Fort Worth) have not kept up with growth, built from public TxDOT, FRA, Census, City of Fort Worth and OpenStreetMap data.

Live page: https://loganlaporte.github.io/76052-road-gaps/
Full data and methods: https://loganlaporte.github.io/76052-road-gaps/details.html

Map data (c) OpenStreetMap contributors (ODbL).
